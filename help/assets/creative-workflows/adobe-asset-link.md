# Adobe Asset Link {#adobe-asset-link}

Adobe Asset Link is a Creative Cloud extension that brings AEM Assets into designers' favorite desktop applications, including Adobe XD, Photoshop, Illustrator, and InDesign.

>[!TIP]
>
> Learn more about how the [Adobe XD Premium Training Program](https://helpx.adobe.com/support/xd.html) can help you integrate Asset Link with your Adobe Experience Manager workflow.

## See a common creative workflow with Adobe Asset Link

This video illustrates a common workflow for creatives working in Adobe Creative Cloud applications, integrating directly with AEM using Adobe Asset Link.
