# Bulk import {#bulk-import}

Bulk import brings large volumes of assets from external cloud storage into AEM Assets. Use it to migrate content or import new assets automatically on a schedule, without requiring source contributors to access AEM Assets directly.

>[!BEGINTABS]

>[!TAB Assets view]

Use bulk import for large migrations or regular asset deliveries from agencies and partner teams. Reusable configurations and scheduled imports reduce manual uploads while preserving the source folder structure.

This video shows how to import assets from Microsoft OneDrive in the Assets view, filter out unwanted files, and preview an import with a dry run before you commit.

>[!VIDEO](https://video.tv.adobe.com/v/3505039/?learn=on&enablevpops)

See the [bulk import documentation](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/assets/assets-view/bulk-import-assets-view) for setup instructions and supported cloud storage providers.

>[!TAB Admin view]

Learn how to use the bulk import tool in the Admin view to import assets from cloud storage into AEM Assets. This video demonstrates Azure Blob Storage and Amazon S3 as input sources.

>[!VIDEO](https://video.tv.adobe.com/v/329680?quality=12&learn=on)

See the [Admin view bulk import documentation](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/assets/manage/add-assets#bulk-upload) for the current list of supported sources and schedule options.

>[!ENDTABS]
