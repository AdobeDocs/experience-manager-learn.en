# Dynamic Media {#dynamic-media}

See how Dynamic Media renditions show up in the Assets view, and where Dynamic Media configuration lives in the Admin view.

>[!BEGINTABS]

>[!TAB Assets view]

See how Dynamic Media renditions for an asset show up directly in the Assets view, so you can review responsive images and interactive viewers as part of your regular asset workflow.

>[!VIDEO](https://video.tv.adobe.com/v/3503497/?learn=on&enablevpops)

>[!TAB Admin view]

Dynamic Media configuration and setup still happen in the Admin view. For a complete walkthrough, refer to the [Dynamic Media overview](https://experienceleague.adobe.com/en/docs/experience-manager-learn/assets/dynamic-media/dynamic-media-overview-feature-video-use).

>[!ENDTABS]
