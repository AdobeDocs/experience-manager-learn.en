# Provision the Assets view {#provisioning}

Before a team can use AEM Assets, someone has to set it up and decide who gets in. A clean setup keeps the environment secure from day one and saves the admin team from cleanup work later. This page shows how to deploy the Assets view and grant the right people access to it.

>[!BEGINTABS]

>[!TAB Admin view]

In the Admin view, use the Adobe Admin Console to assign users to the AEM Assets product after your organization gets the entitlement. This video walks through the full setup: you accept administrator rights, navigate to the product in the console, and add the users who set up and manage the instance.
