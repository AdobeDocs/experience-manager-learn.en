# Metadata schemas and forms {#metadata-schemas-and-forms}

AEM Assets lets you define the metadata fields available on assets and folders, whether you use the Assets view or the Admin view.

>[!BEGINTABS]

>[!TAB Assets view]

## Configure metadata forms

Build and tailor the metadata fields available to your team from Metadata Forms. This video shows the whole flow.

>[!VIDEO](https://video.tv.adobe.com/v/3431686?quality=12&learn=on)

>[!TAB Admin view]

## Configure metadata schemas

A metadata schema defines the fields users see and fill in on an asset. This video shows how to build one.

>[!VIDEO](https://video.tv.adobe.com/v/33696?quality=12&learn=on)

## Configure metadata profiles

A metadata profile applies default metadata to assets automatically, based on the folder where you upload them. This video shows how to set one up.

>[!VIDEO](https://video.tv.adobe.com/v/33974?quality=12&learn=on)

## Configure metadata folder schemas

A folder schema lets you manage metadata on a folder itself, instead of on each asset inside it. This video shows how to configure one.

>[!VIDEO](https://video.tv.adobe.com/v/34071?quality=12&learn=on)

>[!ENDTABS]
