# Comments, annotations, and tasks {#comments-annotations-and-tasks}

AEM Assets lets you discuss, mark up, and route assets for review, whether you use the Assets view or the Admin view.

>[!BEGINTABS]

>[!TAB Assets view]

## Comment, annotate, and assign tasks

Add a text, pin, or freeform shape comment on an asset, then assign a review task to the right person. Track task status from My Workspace, on either side of the review.

>[!VIDEO](https://video.tv.adobe.com/v/335856?quality=12&learn=on)

>[!TAB Admin view]

## Comment and annotate

Add comments and annotations to discuss an asset, mention another AEM user to notify them, and export annotations to PDF for reviewers outside AEM.

>[!VIDEO](https://video.tv.adobe.com/v/32049?quality=12&learn=on)

## Review and approve

Create a review task to route assets for approval. Reviewers can approve, reject, request changes, compare assets side by side, and annotate directly from the task.

>[!VIDEO](https://video.tv.adobe.com/v/32050?quality=12&learn=on)

>[!ENDTABS]
