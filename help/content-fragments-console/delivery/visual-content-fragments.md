# Visual Content Fragments

Explore AEM Visual Content Fragments and learn how to transform structured Content Fragments into reusable HTML experiences. In this video, you'll see how HTML templates use Handlebars to render content, preview the results, and publish them for use across Edge Delivery Services, AEM Sites, and other web applications. You'll also see how content updates in AEM automatically flow to every consuming channel.

>[!VIDEO](https://video.tv.adobe.com/v/3494271/?learn=on&enablevpops)

For a complete reference of the supported Handlebars syntax, along with examples of advanced use cases such as conditionals, loops, and rendering referenced Content Fragments, check out the [HTML Templates syntax documentation](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/implementing/configuring-and-extending/content-fragments-visualization-templates).
