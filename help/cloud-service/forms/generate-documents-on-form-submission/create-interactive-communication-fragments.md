# Create Interactive Communication Fragments

Learn how to create reusable fragments to streamline interactive document creation for cloud solutions. Reusable fragments are content blocks, such as paragraphs or sections, that can be used across multiple documents. This video explains how to create, edit, and format fragments to ensure uniformity and ease of reuse. Use these fragments to enhance document consistency and efficiency.
