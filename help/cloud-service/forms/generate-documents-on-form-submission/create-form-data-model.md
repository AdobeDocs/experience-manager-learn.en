# Create form data model for profile data

Learn how to build a Form Data Model (FDM) in Adobe Experience Manager (AEM) Forms to retrieve and use profile data from Adobe Experience Platform (AEP). This guide walks you through configuring an FDM with a read-only profile retrieval service, enabling forms to access structured XDM profile attributes. Ensure your setup is tested and validated before binding to adaptive forms or interactive communications. Watch the video below for detailed instructions and demonstrations.
