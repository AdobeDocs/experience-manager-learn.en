# Creating custom actions in AJO

Learn how to create custom actions in Adobe Journey Optimizer (AJO). The custom action is based on the REST API exposed by the Node.js application deployed on Render.
When invoked, the service uses the AEM Forms API to generate a PDF based on a recipient's profile information and document ID. The generated PDF is sent as an email attachment via SendGrid. This functionality is integrated into AJO as a custom action, allowing dynamic mapping of constant values and profile attributes to the REST API payload.

This process enhances personalized communication and streamlines automated workflows. Watch the video below for a detailed walkthrough on configuring and using this feature.
