# Using the Associate UI


The Associate UI is a specialized, simplified interface built on top of Interactive Communications (IC) editor. It is designed for customer-facing professionals, such as field associates and service representatives, to generate personalized, compliant, and accurate communications in real time during live interactions. 

The document created earlier in this tutorial is enabled for Associate UI editing. This means the document can be opened and edited directly through the Associate UI rather than only in a standalone editor. The Associate UI is designed to be embedded within your corporate application, allowing users to view and edit documents without leaving your application's workflow.

The tutorial also provides [sample code](assets/launch-associate-ui.zip) that demonstrates how to launch the Associate UI from your application. You can use this sample as a starting point and customize it to fit your application's authentication, document handling, and user experience requirements. In a typical integration, your application passes the required document context to the Associate UI, which then loads the document and enables editing within the embedded interface.

For complete integration guidance, configuration options, supported APIs, authentication requirements, and customization capabilities, refer to the [Associate UI documentation.](https://experienceleague.adobe.com/en/docs/experience-manager-cloud-service/content/interactive-communication/associateui/associate-ui-in-interactive-communication-editor)
