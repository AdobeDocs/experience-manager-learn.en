## Creating a ZIP Code Lookup for the Contact Us Form

The next enhancement is to make the address fields more efficient by allowing the user to enter a ZIP Code and automatically populate the corresponding **City** and **State**.

The intended experience is:

1. The user enters a ZIP Code.
2. The ZIP Code is sent to an address lookup API.
3. The API returns the corresponding City and State.
4. The Adaptive Form populates the City and State fields.

### Current Coworker Capability

At this stage, Coworker cannot create the complete AEM integration required for this lookup.

In particular, Coworker cannot currently create:

- The AEM **Data Source**
- The **Form Data Model (FDM)** required to consume the API

However, Coworker can assist with the API integration by generating the **Swagger/OpenAPI definition** from the API's GET command.

This means the implementation is currently a combination of Coworker-assisted and manual AEM configuration:


## Step 1: Ask Coworker to Generate the Swagger Definition

Provide Coworker with the API GET command and ask it to generate the Swagger/OpenAPI definition needed for the AEM integration.

Use the following prompt:

```text
Please generate API definition (Swagger) file for the Ziptastic service, https://ziptasticapi.com/94086
```

## Step 2 : Create the Form Data Model

Using the Swagger file generated by Coworker, create the Data Source in AEM and then create a Form Data Model (FDM) based on that Data Source.

Once the Form Data Model is configured, use the Form Data Model Test Editor to test the service. Provide a valid ZIP Code and verify that the service successfully returns the expected City and State values before proceeding to the next step.

## Step 3: Ask Coworker to use the created service to do the ZipCode lookup

Once the Data Source and Form Data Model service are available and have been tested successfully, ask Coworker to configure the ZIP Code lookup behavior in the Contact Us form.
