# Create interactive communication template

Interactive communication templates help ensure consistency and scalability in creating customer documents. They provide predefined structures for layouts and components, enabling teams to quickly produce personalized and compliant communications.

This page covers how to create an interactive communication (IC) template and use it as the foundation for documents. It explains adding subforms for dynamic content, managing master pages for consistent layouts, and enabling the template for reuse.
