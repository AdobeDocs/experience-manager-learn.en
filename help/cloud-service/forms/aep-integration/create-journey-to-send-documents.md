# Automate journeys for interactive communications

Discover how to automate the creation and delivery of interactive communications using Adobe Journey Optimizer. This process involves creating a journey triggered by real-time audience qualification. The journey uses custom actions to generate and email personalized documents, leveraging AEM Forms API and SendGrid.
