# Manage your website with the help of AI

Use the [AEM MCP Server](./overview.md) from any AI-powered chat client, such as ChatGPT, Claude, or Cursor, to update your website content and publish changes in natural language, no manual editing in the AEM UI.

In this walkthrough you _find_ a page using natural language search, _generate_ new title copy with AI, _update_ the page and its linked content fragment together, _publish_ the changes live, and _revert_ everything with a single prompt.

>[!VIDEO](https://video.tv.adobe.com/v/3497092/?learn=on&enablevpops)

## Add the AEM MCP Server

Register the following URL in your AI client:

```
https://mcp.adobeaemcloud.com/adobe/mcp/aem
```
