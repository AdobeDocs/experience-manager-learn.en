# Bulk import {#bulk-import}

Moving a large asset library to AEM as a Cloud Service one upload at a time is slow and error-prone. Bulk import reads assets directly from your cloud storage, so you avoid manual uploads and keep your source folder structure.

Run an import once for a migration, or schedule recurring imports to pick up new assets that agencies and partner teams drop into storage. Filters, health checks, and dry runs let you validate each import before you commit.

Choose the video that matches your AEM Assets interface.
